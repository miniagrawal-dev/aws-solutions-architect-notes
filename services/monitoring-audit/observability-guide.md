# CloudWatch vs Prometheus

| CloudWatch | Prometheus |
|------------|------------|

# One-Line Revision

Observability combines **metrics, logs, and traces** to monitor system health, troubleshoot production issues, and optimize application performance. In AWS, **CloudWatch** provides monitoring, **CloudWatch Logs** stores application logs, **AWS X-Ray** enables distributed tracing, **CloudTrail** audits API activity, and **AWS Config** tracks infrastructure configuration changes.
